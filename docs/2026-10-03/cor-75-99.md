# Phase 1 — COR 75–99

## Fast-path loop

1. Set RoE objectives for the zone and enemy family.
2. Use an EXP ring and food when convenient.
3. Summon a balanced Trust party.
4. Fight enemies that die quickly and still grant good experience; move when chains slow down.
5. Stop just before each cap, complete the limit quest, refresh gear only at the checkpoints below, and continue.
6. Advance Rhapsodies whenever its next key item is close.

**Default solo route:** Trust-led Abyssea is a practical continuation for a returning 75 because alter egos are allowed there. Escha and Grounds/Fields of Valor camps may be faster when access, gear, and target density line up. Camp selection is community-maintained and changes with congestion; use the [BG-Wiki 1–99 guide](https://www.bg-wiki.com/ffxi/New_Player_Leveling_Guide) to choose the current camp rather than treating one coordinate as permanent.

If a legitimate player EXP group is already running, join it. Do not wait hours for one—the Trust route is the plan.

## 75 → 80

- [ ] <span data-task-id="cor-gear-75" data-task-phase="level" data-task-required="true"></span> **Assemble a practical level-75 COR set.** Refresh weapon, gun/ammo, and badly obsolete armor with Sparks/NPC/AH pieces. Keep the spend small.
- [ ] <span data-task-id="limit-80" data-task-phase="level" data-task-required="true"></span> **Complete the 80-cap quest, “New Worlds Await.”** The Nomad Moogle in Ru'Lude Gardens begins the post-75 limit sequence. Verify the current merit/item turn-in before farming it.
- [ ] <span data-task-id="cor-80" data-task-phase="level" data-task-required="true"></span> **Reach COR 80.** Prioritize kill speed and survival over perfect marksmanship skill.

## 80 → 90

- [ ] <span data-task-id="limit-85" data-task-phase="level" data-task-required="true"></span> **Complete “Expanding Horizons” for the 85 cap.** Prepare the turn-in while leveling toward 80.
- [ ] <span data-task-id="cor-85" data-task-phase="level" data-task-required="true"></span> **Reach COR 85.** Replace only weak weapon/ammo slots or pieces that create an obvious accuracy problem.
- [ ] <span data-task-id="limit-90" data-task-phase="level" data-task-required="true"></span> **Complete “Beyond the Stars” for the 90 cap.** Confirm the current requirements with the Nomad Moogle or the linked community guide.
- [ ] <span data-task-id="cor-90" data-task-phase="level" data-task-required="true"></span> **Reach COR 90.** Keep Rhapsodies and RoE moving; do not stop for a full level-90 set.

## 90 → 99

- [ ] <span data-task-id="limit-95" data-task-phase="level" data-task-required="true"></span> **Complete “Dormant Powers Dislodged” for the 95 cap.** Bank merits before the cap blocks experience.
- [ ] <span data-task-id="cor-95" data-task-phase="level" data-task-required="true"></span> **Reach COR 95.** This is the last point where temporary pre-item-level gear makes sense.
- [ ] <span data-task-id="limit-99" data-task-phase="level" data-task-required="true"></span> **Complete “Beyond Infinity.”** This cap includes a battle. Use Trusts if the current quest permits them, bring the recommended weakening item if needed, and ask a linkshell for help rather than turning it into a solo wall.
- [ ] <span data-task-id="level-99" data-task-phase="level" data-task-required="true"></span> **Reach COR 99.** Stop the leveling grind and switch immediately to the [post-99 queue](post-99.md).

## Gear checkpoints

| Checkpoint | Do this | Skip this |
| --- | --- | --- |
| Return / 75 | Current weapon, gun, ammunition, cards, food, and functional armor | Farming old 75-era best-in-slot |
| 75–80 | Use Sparks/NPC/AH upgrades when a key slot is far behind | Replacing every slot for a five-level window |
| 80–90 | Refresh weapon/ammo and obvious accuracy/survival gaps | Expensive rare drops with no 99 use |
| 90–98 | Spend minimally; save Sparks and inventory space for 99 | Building a complete level-90 or 95 set |
| First minute at 99 | Buy/claim an i117 weapon, gun, ammo option, and wearable baseline | Starting JP in old equipment |
| i117 → i119 | Replace the whole baseline through tutorial objectives and Ambuscade | Chasing premium COR weapons before the support floor works |

### COR priorities while leveling

1. Keep ammunition and cards stocked.
2. Learn the dice for the rolls your Trust party benefits from.
3. Use two sensible rolls, stay in range of the intended recipients, then contribute safe damage.
4. Keep melee, marksmanship, and relevant skills moving, but do not halt the EXP route solely to cap every skill.

Exact camp and limit-break requirements above are **community guidance reviewed October 3, 2026**. Verify them in game or on the linked BG-Wiki pages before spending rare currency.
